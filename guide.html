MedCare - Developer & User Manual

Welcome to the official developer and end-user guide for MedCare, a high-performance HTML5 template engineered specifically for modern healthcare facilities, clinics, hospitals, and private practices.

Core Highlights: Pure W3C Valid HTML5, Native CSS Variables, Zero-dependency Light/Dark Mode, Pure JavaScript Validation, Ultra-Fast Load Speed, and Native Mobile Responsiveness.

1. Quick Start & Deployment

Deploying MedCare to a live Web Server (cPanel, Netlify, Vercel, or Apache/Nginx) is straightforward:

  1. Unzip the downloaded MedCare.zip package on your local computer.
  2. Upload all files and folders (css/, js/, guide/, and all .html files) to your server's root directory (usually public_html/).
  3. Open your domain in any modern browser to verify the site is running live.

4. CSS Variables Reference

You can customize the full theme palette by modifying variables inside css/style.css in the :root block:

Variable Name Default Hex / Value Purpose / Applied Components
--primary-color #0d6efd Primary brand color used in buttons, active icons, and links.
--primary-hover #0b5ed7 Hover state color for primary buttons and interactive elements.
--bg-main #ffffff Main body background color in Light Mode.
--bg-secondary #f8f9fa Background color for cards, sections, and input fields.
--text-primary #212529 Main heading and body text color in Light Mode.
--text-muted #6c757d Secondary paragraphs, subtitles, and placeholder text.

5. Dark Mode System Architecture

Dark mode is driven by appending .dark-mode class to <body> via js/main.js, and uses browser localStorage to remember theme settings across pages.

To adjust Dark Mode colors, edit the body.dark-mode block in css/style.css:

body.dark-mode {
    --bg-main: #0b0f19;          /* Dark mode body background */
    --bg-secondary: #111827;     /* Dark mode card background */
    --text-primary: #f8fafc;     /* Dark mode main title text */
    --text-muted: #94a3b8;       /* Dark mode secondary text */
    --border-color: #1e293b;     /* Dark mode borders */
}

6. Form & Backend Integration Guide

The forms on index.html and contact.html feature pure JS front-end validation. To receive email submissions on a live server, choose one of these options:

Option A: Using Formspree (No Server Code Required)

1. Create a free account on Formspree.io.

2. Replace the <form> tag in your HTML page with your Formspree endpoint:

<form action="https://formspree.io/f/YOUR_FORM_ID" method="POST" id="contactForm">

Option B: Connecting a PHP Script

Set your form action to point to a backend PHP script on your hosting server:

<form action="send-email.php" method="POST" id="bookingForm">
Note: Front-end validation rules inside js/main.js will run first to verify user input before handing off the payload to your backend service.

7. Content Editing Guide

A. Editing Doctors Directory (`doctors.html`)

To add a doctor profile card, duplicate the following block inside the grid container:

<div class="doctor-card">
    <div class="doctor-icon">
        <i class="fa-solid fa-user-doctor"></i>
    </div>
    <h3>Dr. Sarah Johnson</h3>
    <p>Pediatric Specialist</p>
    <a href="index.html" class="btn btn-primary">Book Appointment</a>
</div>

B. Changing Font Awesome Icons

You can swap icons anywhere by changing class names on the <i class="..."></i> element:

  • fa-solid fa-user-doctor (Doctor icon)
  • fa-solid fa-heart-pulse (Cardiology icon)
  • fa-solid fa-phone (Phone / Contact icon)
  • fa-solid fa-clock (Working Hours icon)

8. SEO & Performance Optimization

  • No Heavy External Assets: Zero heavy images or large JS frameworks, resulting in extremely fast page load scores.
  • Meta Tags: Each HTML file includes responsive viewport meta tags. Be sure to update <title> and <meta name="description"> tags for production SEO.
  • Clean W3C Code: All markup adheres strictly to modern HTML5 standards.
